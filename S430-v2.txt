## 🔧 Notes / Tips
- fs.watch behaviour is platform-specific — events can be `rename` when a new file is created. The library exposes `eventType` in the `change` event; the README now shows both `eventType` and `filename`.
- `watchOnce` is deprecated — use `waitForFile` (documented).
- The `filter` option expects either a string or a RegExp. The tests use RegExp examples like `/\\.log$/`.
- `logFile`: the library uses synchronous append which is fine for small workloads (and simple logging), but if you plan heavy logging consider a buffered/asynchronous approach.
